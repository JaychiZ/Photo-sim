# 摄影模拟器

*PHOTOGRAPHY SIMULATOR*

[**进入游戏**](https://jaychiz.github.io/Photo-sim/)

背上一台相机，走进三个世界：雪山湖泊、湖心别墅、霓虹城的街头。

光圈开大，背景就化开；快门放慢，车灯拉成光轨，浪花变成薄雾；夜里对着星空，要等够真实的秒数才能拍亮。曝光、景深、噪点、焦距全部按真实相机的规律计算，拍出来是什么样，取决于你怎么设置。

时间、天气、月相、地面干湿都能调。猫会舔爪、趴下、摇尾巴，车会停下让人，鸟群从头顶飞过——找好位置，等它们走进画面，按下快门。

## 三个场景

- **自然风光** · 雪山湖泊、海岸码头
- **湖心别墅** · 落地玻璃大厅
- **霓虹城** · 落樱大道、青石小巷、琉璃天桥、听潮湾天际线

**127 款机身 · 428 支镜头**，支持 P / A / S / M 四种拍摄档位。

## 电脑操作

| 按键 | 操作 |
| --- | --- |
| `W A S D` / 鼠标 | 走动 / 转头 |
| `Shift` / `空格` | 跑 / 跳 |
| `C` / `Z` | 蹲下或贴地 / 趴下与猫平视 |
| 左键 / `U` | 举起相机，再按左键拍照 |
| 按住右键 / `F` | 进入取景器 |
| 滚轮 / `← →` / `↑ ↓` | 变焦 / 光圈 / 快门 |
| `[ ]` / `- =` / `M` | ISO / 曝光补偿 / 档位 |
| `Q E` / `9` / 反引号键 | 旋转相机 / 竖拍 / 回正 |
| `I J K L` / `X` | 移动对焦点 / 切换自动和手动对焦 |
| `R` / `1–8` / `N` | 照片与视频切换 / 运镜 / 三脚架 |
| `V` / `Y` | 无人机 / 别墅窗帘 |
| `Tab` / `T` / `G` | 相机 / 场景、时间和天气 / 相册 |
| `P` / `H` / `Esc` | 画质 / 完整帮助 / 释放鼠标 |

## 手机和平板操作

| 屏幕控件 | 操作 |
| --- | --- |
| 左下摇杆 / 拖动画面 | 走动 / 转头 |
| 右下「举起」和「拍照」 | 举起相机，再按「拍照」 |
| 点画面 | 移动对焦点 |
| 底部「− 参数 ＋」 | 调整快门、光圈和 ISO |
| 「变焦＋ / −」和「竖拍」 | 变焦 / 横竖切换 |
| 顶部按钮 | 相机、场景与天气、相册和画质 |

手机和平板建议横屏。默认画质为「流畅」，电脑性能好可以按 `P` 调高。

也可以下载 [index.html](index.html)，用浏览器离线打开。

## 从源码构建

下载 [源码压缩包](photo-sim-source.zip) 并解压。在解压后的目录中，用 Node.js 运行以下命令。构建结果是 `index.html`。

```bash
npm ci
node build.mjs
```

`src/` 中的脚本、天空贴图和游戏使用的小型模型一起打包为单个 HTML。
